# Кушать — ценники для Windows

Локальная программа для печати ценников из справочника R-Keeper на установленном
принтере Windows. A4, четыре ценника **100 × 140 мм** или **140 × 100 мм**, масштаб 100%.
Можно выбрать несколько товаров и отдельное количество экземпляров для каждого.

## Скачать

[**Кушать 0.5.0 для Windows x64, ZIP**](https://github.com/lemeschenkoartem/kushat/raw/refs/heads/downloads/Kushat-0.5.0-win-x64.zip)

Закройте старую программу, распакуйте архив в новую папку и запустите `Kushat.exe`.
Поддерживаются Windows 10 22H2 / Windows 11 x64. .NET отдельно устанавливать не требуется.
В заголовке окна должна быть версия **0.5.0**. Иконка встроена в EXE и окна программы.
Архивы и `SHA256SUMS` находятся в ветке `downloads`.

## Подключение и автоматический вход

1. Нажмите **«Подключения…»**.
2. Для нового объекта нажмите **«Новое подключение»**. При желании задайте название.
3. Укажите **его** адрес и порт: `https://сервер:порт` или `http://сервер:порт`.
   Без протокола используется HTTP. Для Reference-сервера применяется встроенный
   XML-интерфейс `/rk7api/v0/xmlinterface.xml`, HTTP Basic.
4. Введите название работника R-Keeper и его пароль. У работника должны быть права HTTP/XML.
5. Оставьте **«Запомнить вход на этом компьютере»** и нажмите **«Войти и загрузить меню»**.

Программа сохраняет отдельные профили подключений. После следующего запуска она
восстанавливает вход в последний выбранный профиль и загружает свежие данные с сервера.
Обновление меню не требует повторного ввода пароля. Тип цены **«Основной»** выбирается
автоматически; поддерживается также название **«Основная»**. Если такого типа нет,
единственный выбирается сам, при нескольких предлагается выбор. При обновлении
сохраняется тип цены, вручную выбранный в текущем сеансе.

Пароль сохраняется **в зашифрованном виде средствами Windows DPAPI CurrentUser**,
с привязкой к адресу, порту, протоколу и названию работника. Открытого пароля в JSON нет.
При редактировании адреса или работника подставленный пароль очищается.
Кнопка **«Выйти»** удаляет сохранённый вход активного профиля и очищает сеанс.
При отказе авторизации сохранённый вход сбрасывается; временная ошибка связи его не удаляет.
Если пароль не нужно сохранять, снимите флажок при входе.

Настройки хранятся в `%LOCALAPPDATA%\Kushat\settings.json` для текущего пользователя Windows.
Адрес, логин и принтер из 0.1.x переносятся автоматически; старые версии пароль не сохраняли,
поэтому первый вход после обновления выполняется вручную.
Для распространения передавайте ZIP программы, а не свою папку настроек.

## Проверка сервера и мастер сертификата

Перед входом программа проверяет TCP-порт и HTTPS-сертификат без отправки логина и пароля.
В окне входа есть отдельная кнопка **«Проверить порт и сертификат»**; в главном окне
показывается срок сертификата. Об ошибке и сроке менее 30 дней выводится сообщение.

Кнопка **«Сертификат…»** или файл `Certificate-Wizard.cmd` открывают встроенный мастер:
автоматический поиск локального RefSrv и сертификатов без ввода IP/порта → проверка срока → резервная копия → подтверждённая остановка
службы/процесса/порта → установка и доверие → проверка запуска и нового отпечатка →
**«Завершить»**. Службу можно остановить/запустить кнопками в мастере.
При просроченном сертификате «Далее» заблокирована: доступна «Выпустить новый сертификат». Имена и IP компьютера включаются автоматически. Добавлены «Назад» и «Отмена».
Для настройки на сервере нужны права администратора.

[Пошаговая инструкция мастера, клиентское доверие и откат](docs/certificate-wizard.md).
Если программа печати на другом компьютере, сам файл сертификата меняется на Reference-сервере,
а на клиенте кнопка **«Доверие из .cer…»** в окне входа проверяет и импортирует публичный `.cer` этого сервера.

## Товары, единицы и цены

Читаются `GetRefData` справочников `PriceTypes`, `MenuItems` и групп `CategList`. WSA2, AgentGuid и прямое
подключение к SQL не используются. Чтение и печать не изменяют справочники R-Keeper.
Доступность интерфейса и коммерческие условия зависят от установки R-Keeper;
программа не приобретает лицензии. [Источники и особенности Reference API](docs/reference-server.md).

Единица определяется по **режиму цены** в R-Keeper, а не по названию товара или
возможности дробного количества:

- **Штучное** — цена за одну штуку, цена за 100 г не выводится.
- **Порционное за вес**, единица кг — исходная цена за кг пересчитывается в цену за 100 г.
- **Порционное за стандартную порцию**, единица кг — пересчёт цены порции в цену за кг
  с использованием её веса. Например, 350 ₽ за 250 г → 1400 ₽/кг → 140 ₽/100 г.

В таблице показана единица цены. Если режим, единица или вес порции не определены,
товар остаётся видимым с пояснением у единицы, но выбрать его для печати нельзя.
Литры, дозы и неизвестные режимы автоматически не подменяются килограммами.
Служебное значение отсутствующей цены `9223372036854775807` не печатается.

Макросвойства `PRICETYPES-<Ident>` читаются как денежные значения в рублях.
Для нативного XML поддержаны именованные режимы `pmPerPiece`, `pmPerUnitOfWeight`,
`pmPerPortion`; в последнем случае ожидается целочисленный `PortionWeight` в граммах.
Перед первым тиражом на каждом новом сервере сверьте реальные цену и вес порции:
формат конкретной установки должен соответствовать этим данным. Неизвестный формат
требует адаптации по реальному ответу, а не ручной подмены единицы.

Пересчёт выполняется десятичной арифметикой. Цена за 100 г считается из исходной
пересчитанной стоимости, без повторного округления цены за кг. Округление — до копеек
от середины вверх: 315,55 ₽/кг → 31,56 ₽/100 г.

## Ветки меню

Слева находится дерево реальных групп R-Keeper с количеством товаров. Выберите
ветку: в таблице останутся её товары и товары всех подветок. Поиск по наименованию
или идентификатору работает внутри выбранной ветки. **«Все товары»** возвращает
общий список; **«Без доступной группы»** содержит товары, для которых не найдена группа.

Переключение ветки и поиск **не сбрасывают выбранные товары и количество ценников**.
Можно набрать одно задание из разных веток. **«Выбрать найденные»** отмечает только
видимые товары; **«Снять весь выбор»** очищает выбор во всех ветках.
Панель можно скрыть кнопкой **«Скрыть ветки»** или изменить её ширину разделителем.
Если доступ к группам ограничен, выводится сообщение и сохраняется общий список товаров.
Демо-режим содержит кухню с подветками «Салаты»/«Горячие блюда» и отдельную «Выпечку».

## Шаблоны и печать

Справа выберите вертикальный **100 × 140 мм** или горизонтальный **140 × 100 мм**
ценник. Для горизонтального варианта A4 становится альбомным; на листе остаются
четыре ценника, масштаб 100%. Ориентация сохраняется.

Выберите один из пяти вариантов:

1. **Классический** — название по центру.
2. **Крупная цена** — акцент на цене за 100 г или за штуку.
3. **С акцентной полосой** — зелёная полоса и крупная цена.
4. **Меловой · чёрный фон** — белые надписи на тёмном фоне, название курсивом.
5. **Кафе · полосатая рамка** — чёрно-белое оформление с полосатым навесом.

Во всех шаблонах **название сверху, цена снизу**. Выводится ровно одна цена:
за **100 г** для весовых или за **штуку** для штучных товаров. Варианты за кг и
две цены убраны. Старые настройки этих режимов автоматически заменяются на новый
формат. В таблице показана та же цена и её единица. Шаблон, ориентация и принтер
сохраняются, образец обновляется сразу.
Все шаблоны используют выбранную ориентацию: 100 × 140 мм или 140 × 100 мм.

Отметьте товары, задайте количество, выберите принтер и откройте **предварительный просмотр**.
В печать попадут все отмеченные товары, включая скрытые веткой меню или поиском.
Максимум — 1000 ценников за раз, от 1 до 999 экземпляров одного товара.
Драйвер должен поддерживать поля не более 5 мм по бокам и 8,5 мм сверху/снизу
для вертикальных ценников (8,5 мм и 5 мм соответственно для горизонтальных);
иначе программа предложит выбрать другой принтер или его режим A4.
Печать выполняется в масштабе 100%, без уменьшения ценников.

**«Демо-товары»** позволяют проверить шаблоны без сервера: есть весовой и штучный товары,
каждый ценник помечается как демонстрационный.

## Развёртывание на других серверах

[Пошаговая инструкция](docs/deployment.md): свои адреса/порты, работники и HTTPS-сертификаты.
Для собственного сертификата Reference-сервера используется документированный
`mylocal.pem`, [утилита 2.0.0 и инструкция](docs/reference-certificate.md).
Публичный платный сертификат для локальной сети не обязателен: можно создать свой
и настроить доверие на клиентских компьютерах. Проверка TLS в программе включена.
Порт не входит в сертификат; IP/DNS из адреса должен присутствовать в SAN.

Коды `HTTP_401/403` относятся к учётной записи/правам, `TLS_CERTIFICATE` — к сертификату.
В окне входа есть кнопка **«Скопировать ошибку»**. Пароль и тела ответов в диагностику не включаются.

## Разработка и проверки

.NET SDK 10. В Linux поддерживаются тесты Core и кросс-сборка WPF:

```bash
bash scripts/check.sh
```

На Windows скрипт дополнительно выполняет нативные проверки DPAPI и WPF, затем собирает ZIP:

```powershell
./scripts/build-windows.ps1
```

Проверки покрывают профили и миграцию, привязку зашифрованного входа к объекту,
пересчёт порций и округление, выбор единицы и вывод цены, шаблоны, ограничения A4,
ошибки HTTP/XML/TLS. GitHub Actions выполняет проверки Windows при push в main,
ручном запуске и создании тега `v*`. Тег также публикует GitHub Release после успешной сборки.
Физическая печать и реальные поля новой установки проверяются на месте.
