# Кушать 0.4.0 для Windows x64

Скачайте **Kushat-0.4.0-win-x64.zip**, закройте старую программу, распакуйте в новую
папку и запустите Kushat.exe. .NET устанавливать отдельно не нужно.

Мастер сертификата больше не требует IP и порта. Запустите Certificate-Wizard.cmd
на Reference-сервере: служба RefSrv, сертификат и его срок определяются автоматически.
Если срок истёк, «Далее» заблокирована и доступна «Выпустить новый сертификат».
В сертификат включаются имена и IP компьютера. Сохранены резервная копия, штатная
остановка/запуск службы, проверка предъявляемого сертификата, доверие и откат.
Добавлены «Назад» и «Отмена». После установки возврат не выполняет её повторно.
Для изменения сертификата и управления службой нужны права администратора.

Все пять шаблонов работают вертикально (100 × 140 мм) и горизонтально (140 × 100 мм).
Для горизонтальных ценников А4 становится альбомным: четыре ценника, масштаб 100%.
Ориентация сохраняется вместе с настройками. Предпросмотр и проверка полей принтера
учитывают выбранный формат.

На клиентском компьютере импорт публичного .cer доступен в окне входа кнопкой
«Доверие из .cer…». Программа поддерживает HTTP и HTTPS. Протокол должен совпадать
с настройкой порта; выпуск сертификата не переводит TLS-порт на HTTP.

Сохранены профили подключений, защищённый DPAPI вход и автовход, выбор принтера,
определение кг/шт, вывод цены за кг / 100 г / обеих цен, основной тип цены.
В архиве нет ваших настроек, паролей или закрытых ключей сертификата.

Отдельная CLI-утилита **Kushat-CertificateTool-2.0.0-win-x64.zip** сохранена для работы
командами prepare/install/rollback. Для обычной настройки используйте встроенный мастер.
Утилита 1.0.0 сохранена только для истории: её install заменял default.pem.
**Не используйте версию 1.0.0.** Старые версии приложения сохранены в отдельных архивах.
