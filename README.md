# Кушать 0.3.0 для Windows x64

Скачайте **Kushat-0.3.0-win-x64.zip**, закройте старую программу, распакуйте в новую папку
и запустите Kushat.exe. .NET устанавливать отдельно не нужно.

Встроенный мастер сертификата открывается кнопкой «Сертификат…» или файлом
Certificate-Wizard.cmd без входа в R-Keeper. На компьютере Reference-сервера он ищет
службу RefSrv, порт и сертификат, проверяет срок, создаёт резервную копию и новый
сертификат, настраивает доверие Windows. «Далее» появляется только после полной
остановки службы, процесса и порта. После установки мастер сообщает, что сервер
можно включить, и проверяет запуск и новый сертификат. Затем доступна «Завершить».
Службу можно штатно остановить и запустить кнопками. Для изменения нужны права администратора.

Если приложение работает на другом компьютере, замену выполняют на Reference-сервере,
а на клиенте мастер импортирует только проверенный публичный .cer этого сервера.
Перед каждым входом и обновлением меню проверяются TCP-порт и HTTPS-сертификат.
Пароль не отправляется до успешной предварительной проверки.

Сохранены профили IP/портов, защищённый Windows DPAPI вход, иконка, пять шаблонов,
определение кг/шт, выбор вывода 1 кг / 100 г / обеих цен и основной тип цены.
Архив не содержит ваших настроек, паролей или закрытых ключей сертификата.

физическая печать и формат данных нового объекта проверяются на месте.
SHA256SUMS содержит контрольные суммы. Kushat-reference-win-x64.zip — тот же архив 0.3.0.

Отдельная CLI-утилита **Kushat-CertificateTool-2.0.0-win-x64.zip** сохранена для работы
командами prepare/install/rollback. Для обычной настройки используйте встроенный мастер.
Утилита 1.0.0 сохранена только для истории: её install заменял default.pem.
**Не используйте версию 1.0.0.** Старые версии приложения сохранены в отдельных архивах.
