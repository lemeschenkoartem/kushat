# Скачать программу

Скачайте `Kushat-reference-win-x64.zip` из этой ветки, распакуйте и запустите `Kushat.exe` на Windows x64.

Исходники: ветка main, коммит 39bb1af56f3ebdccfc6d69b1b0f252c40d071e6e.
В архиве: приложение, инструкция и сведения о сборке. Контрольная сумма — в SHA256SUMS.

Подключение реализовано через встроенный HTTPS XML-интерфейс R-Keeper по адресу сервера, логину и паролю сотрудника.
Это не прямое подключение к SQL. Реальный вход на сервер 7.25.08.005 и физическую печать ещё нужно проверить у клиента.
