# Кушать 0.2.0 для Windows x64

Скачайте **Kushat-0.2.0-win-x64.zip**, закройте старую программу, распакуйте в новую папку
и запустите Kushat.exe. .NET устанавливать отдельно не нужно. Иконка встроена в EXE.

Добавлены профили серверов со своими IP/портами, защищённый Windows DPAPI вход и автовход,
пять шаблонов (включая чёрный с белыми надписями и полосатое кафе), выбор вывода весовой
цены за 1 кг / 100 г / обеих цен. Единица кг/шт определяется по PriceMode R-Keeper.
Тип цены Основной/Основная выбирается автоматически.

Первый раз войдите с флажком «Запомнить вход на этом компьютере». Затем программа
сама загрузит свежие данные при запуске. «Выйти» удаляет сохранённый вход этого профиля.
Архив не содержит ваших настроек, паролей или ключей сертификата.

[Инструкция развёртывания](https://github.com/lemeschenkoartem/kushat/blob/93157ebeca07ba2623248f7107c5ec4b7df70a1b/docs/deployment.md).
Перед тиражом сверьте цену и вес одной стандартной порции на своём сервере.

Исходники: 93157ebeca07ba2623248f7107c5ec4b7df70a1b.
[Проверка Windows](https://github.com/lemeschenkoartem/kushat/actions/runs/39632973464):
117 тестов Core и 39 нативных проверок Windows прошли; сборка ZIP успешна.
Физическая печать и формат данных нового объекта проверяются на месте.
SHA256SUMS содержит контрольные суммы. Kushat-reference-win-x64.zip — тот же архив 0.2.0.

## Сертификат Reference-сервера

Отдельная утилита **Kushat-CertificateTool-2.0.0-win-x64.zip** устанавливает mylocal.pem
с вашим IP/DNS, не заменяя default.pem. Ключ создаётся только на вашем сервере.
[Инструкция](https://github.com/lemeschenkoartem/kushat/blob/93157ebeca07ba2623248f7107c5ec4b7df70a1b/docs/reference-certificate.md).

Утилита 1.0.0 сохранена только для истории: её install заменял default.pem,
который прежний MIDSERV восстанавливал при запуске. **Не используйте версию 1.0.0.**
Старые версии приложения сохранены в отдельных архивах.
