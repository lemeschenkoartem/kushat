# Кушать 0.6.0 для Windows x64

Скачайте **Kushat-0.6.0-win-x64.zip**, закройте старую программу, распакуйте в новую
папку и запустите Kushat.exe. .NET устанавливать отдельно не нужно.

Исправлены денежные единицы нативного XML R-Keeper: 14500 копеек → 145 ₽ за штуку;
35000 копеек при цене за кг → 350 ₽/кг → 35 ₽ за 100 г. Для стандартной порции
учитывается вес. В таблице и ценнике одинаковая цена. Название сверху, цена снизу.

Добавлены три сохраняемые темы: Мята, Индиго и Графит; закруглённые кнопки,
градиентный фон, адаптация окна к экрану и переход панели печати под таблицу
при узком окне. Настройки принтера, ценника и темы плавно раскрываются.
Образец товара, счётчики, предпросмотр и печать находятся вне разделов настроек.

Можно ввести собственные ширину и высоту в мм и сохранить под своим названием
вместе с оформлением. Выберите сохранённый шаблон при следующем запуске.
Количество на А4 и ориентация листа рассчитываются автоматически, масштаб 100%.
Пять оформлений, дерево меню, поиск, выбор товаров/количеств сохранены.
Из главного окна убраны демо и сертификат. Мастер сертификата доступен в окне входа
и через Certificate-Wizard.cmd. Профили, DPAPI-вход и автовход сохранены.
Архив не содержит ваших настроек, паролей и закрытых ключей сертификата.

печать проверяются на объекте.
SHA256SUMS содержит контрольные суммы. Kushat-reference-win-x64.zip — тот же архив 0.6.0.

Старые версии сохранены в отдельных архивах. Утилита сертификата 1.0.0 сохранена
только для истории: **не используйте её**, она заменяла default.pem.
Для текущей настройки используйте встроенный мастер или CLI 2.0.0.
