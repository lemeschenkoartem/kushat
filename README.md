# Скачать программу 0.1.1 — HTTP

Скачайте **Kushat-HTTP-0.1.1-win-x64.zip**. Закройте старую программу, распакуйте ZIP в новую папку и запустите Kushat.exe из неё.
В заголовке окна входа должно быть **0.1.1 · HTTP/HTTPS**.
Локальный HTTP поддерживается; адрес без протокола означает HTTP.

Сообщение «Укажите HTTPS-адрес сервера…» означает запуск старой сборки.
Архив Kushat-reference-win-x64.zip — копия той же новой версии для совместимости ссылок.

Исходники: main, коммит 9729cdeae94cef55410f24a86b2f026e8daf9687. Контрольные суммы: SHA256SUMS.
Пароль не сохраняется. Для HTTPS остаётся стандартная проверка сертификата.
Реальное подключение к R-Keeper и физическая печать требуют проверки у клиента.
