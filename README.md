# Утилита сертификата Reference-сервера 2.0.0

Скачайте Kushat-CertificateTool-2.0.0-win-x64.zip и распакуйте в отдельную папку.
Работает с пользовательским **mylocal.pem**, не заменяет default.pem.
Сертификат и ключ создаются только на вашем сервере, в архиве их нет.

[Инструкция](https://github.com/lemeschenkoartem/kushat/blob/1799254e0db1c1fda83152a4ead55280c19bd958/docs/reference-certificate.md).
Параметры текущей установки: RefSrv.exe, HTTPS 192.168.7.2:8010.
Установка и откат требуют штатной остановки соответствующего Reference-сервера.
Перед использованием проверьте дату и время Windows. Подготовка остановки не требует.

Исходники: 1799254e0db1c1fda83152a4ead55280c19bd958. Проверены 81 тест, кросс-сборка WPF и утилиты.
Windows ACL, доступ к процессам и загрузка PEM реальным RefSrv проверяются на сервере клиента.
Контрольные суммы архивов — SHA256SUMS.

Версия 1.0.0 сохранена только для истории. Её install заменял default.pem;
на прежнем MIDSERV файл восстановился при запуске. **Не используйте версию 1.0.0.**
