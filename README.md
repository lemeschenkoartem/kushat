# Скачать программу

Скачайте Kushat-reference-win-x64.zip, распакуйте и запустите Kushat.exe на Windows x64.

Поддерживаются локальный HTTP и HTTPS. Без указания протокола используется HTTP.
Пароль сотрудника не сохраняется. Для HTTPS применяется стандартная проверка сертификата.

Исходники: main, коммит 1ae9b6cc3c3ea414cb858f91e9c5943a4ac2f8ad. В архиве — инструкция и сведения о сборке.
Контрольная сумма — в SHA256SUMS.

Используется HTTP/HTTPS XML API R-Keeper, не прямой SQL и не TCP-протокол iTCPXML.dll.
Совместимость с реальным сервером клиента и физическую печать ещё нужно проверить.
