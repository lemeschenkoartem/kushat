# Скачать программу 0.1.2

Скачайте Kushat-HTTP-0.1.2-win-x64.zip, закройте прежнюю программу, распакуйте архив в новую папку и запустите Kushat.exe.
В заголовке окна входа должно быть 0.1.2 · HTTP/HTTPS.

Добавлены подробные коды ошибок сети, HTTP и сертификата, а также кнопка «Скопировать ошибку».
Проверка TLS сохранена: недоверенные сертификаты отклоняются. Настраивайте доверие только к проверенному сертификату сервера.
Пароль и тела запросов/ответов в диагностику не включаются.

Исходники: main, коммит c1ad78185549c72fb8898b55e5effcbe82f63d2a. Контрольные суммы — SHA256SUMS.
Реальный вход и физическая печать ещё требуют проверки у клиента. Предыдущие версии сохранены.

## Локальный сертификат R-Keeper

[Kushat-CertificateTool-1.0.0-win-x64.zip](Kushat-CertificateTool-1.0.0-win-x64.zip) — отдельная утилита подготовки, замены и отката подтверждённого просроченного default.pem.

Сначала прочитайте [инструкцию](https://github.com/lemeschenkoartem/kushat/blob/0dbae6a/docs/local-certificate.md). Подготовка не меняет рабочий сервер. Установка и откат требуют штатной остановки MIDSERV. Ключи создаются только на компьютере пользователя; в архиве ключей нет.

Исходники утилиты: main, коммит 0dbae6a. Проверено: 67 тестов и сборка. Фактическая замена на Windows и загрузка PEM конкретным MIDSERV в облачной среде не проверены.
