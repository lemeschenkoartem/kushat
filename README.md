# Кушать 0.5.0 для Windows x64

Скачайте **Kushat-0.5.0-win-x64.zip**, закройте старую программу, распакуйте в новую
папку и запустите Kushat.exe. .NET устанавливать отдельно не нужно.

Слева добавлено дерево веток меню R-Keeper. Выбор группы показывает товары всех
её подветок; поиск работает внутри выбранной ветки. «Все товары» возвращает весь
список. Выбранные товары и количества сохраняются при переходе между ветками.
«Выбрать найденные» отмечает только видимое, «Снять весь выбор» очищает все ветки.
Панель можно скрыть или изменить её ширину разделителем.

Группы читаются из справочника CategList Reference-сервера. Товары без доступной
группы остаются в общем списке и отдельной ветке. Если группы недоступны, программа
сообщит об этом и сохранит доступ к товарам. Для проверки есть дерево в демо-режиме.

Во всех пяти шаблонах название сверху, одна цена снизу: за 100 г для весовых
или за штуку для штучных. Вывод за кг и двух цен убран. В таблице показана та же
цена, что на ценнике. Старые настройки режимов автоматически переводятся в новый формат.
Вертикальный (100 × 140 мм) и горизонтальный (140 × 100 мм) варианты сохранены:
четыре ценника на А4, масштаб 100%, лист поворачивается автоматически.

Сохранены выбор принтера, профили подключений, DPAPI-вход и автовход, основной
тип цены, определение весовых/штучных товаров и мастер сертификата с «Назад»/«Отмена».
Архив не содержит ваших настроек, паролей или закрытых ключей сертификата.
