# Протокол подключения

Вход выполняется по адресу сервера с портом XML-интерфейса, логину и паролю сотрудника.
Используется встроенный интерфейс R-Keeper `/rk7api/v0/xmlinterface.xml` через HTTPS и HTTP Basic.
WSA2, AgentGuid и прямой доступ SQL не используются.

Выполняются два POST-запроса чтения: `GetRefData` с `RefName="PriceTypes"` и `RefName="MenuItems"`,
`OnlyActive="1"`, `WithChildItems="2"`, `WithMacroProp="1"`.
Ожидаются `RK7QueryResult Status="Ok"`, успешный `CommandResult` и `RK7Reference/Items/Item`.
Тип цены выбирается по `Ident`, соответствующему макросвойству `PRICETYPES-<Ident>` элемента меню.
Значение макросвойства трактуется как рубли. Перед эксплуатацией обязательно сверьте цены с R-Keeper.

Основание для реализации — открытые примеры протокола:

- https://github.com/alexandr-andreyev/rk7-xml-apiclient — request.go, getRefData.go, types_test.go;
- https://github.com/Muromets812/rk7_menu_loader — menu.xml, prices.xml.

Код этих проектов в приложение не включён. Из них не перенесено отключение TLS-проверки.
Эти примеры не доказывают совместимость с реф-сервером клиента. Нужны проверка доступного интерфейса,
авторизации сотрудника, формата цен и конкретного типа цены на версии 7.25.08.005.
Если сервер не возвращает макросвойства цен, приложение сообщит об этом; чтение цен нужно адаптировать по реальному ответу.
