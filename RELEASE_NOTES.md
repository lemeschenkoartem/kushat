Версия 0.5.0 для Windows x64.

Добавлено дерево веток меню R-Keeper: родительская группа показывает товары всех
подветок, поиск работает внутри выбранной ветки. В корне «Все товары» доступен весь
список. Выбор товаров и количества сохраняются при переходе между ветками.
«Выбрать найденные» отмечает только видимые товары, «Снять весь выбор» очищает всё
задание. Панель веток можно скрыть или изменить её ширину.

Группы читаются с Reference-сервера через CategList. Товары без доступной группы
остаются видимыми. При недоступности справочника групп сохраняется общий список
с пояснением. Демо-режим позволяет проверить дерево без сервера.

Все пять шаблонов переработаны: название сверху, цена снизу, в вертикальном
и горизонтальном формате. Одна цена: за 100 г для весовых или за штуку для штучных.
Выбор цены за килограмм и двух цен убран. В таблице показана та же цена, что на ценнике.
Старые настройки автоматически переводятся в новый формат.
Четыре ценника на А4, масштаб 100%, выбор принтера и мастер сертификата сохранены.

Распакуйте архив в новую папку и запустите Kushat.exe. .NET отдельно не требуется.
