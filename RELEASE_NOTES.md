Версия 0.4.0 для Windows x64.

Мастер сертификата больше не требует IP и порта: сам ищет локальную службу RefSrv,
её установку, сертификат и HTTPS-порт процесса. Проверка срока работает и при
остановленном сервере. При просроченном сертификате «Далее» блокируется;
доступна «Выпустить новый сертификат». Имена и IP компьютера включаются автоматически.
Сохранены резервная копия, проверка остановки/запуска службы, доверие и откат.
Добавлены «Назад» и «Отмена». Навигация не повторяет уже выполненную установку;
отмена после изменений сообщает фактическое состояние перед выходом.

Для всех пяти шаблонов доступна ориентация ценника: вертикальный 100 × 140 мм
или горизонтальный 140 × 100 мм. Выбор сохраняется. А4 автоматически поворачивается
для горизонтального варианта, четыре ценника на листе, масштаб 100%.
Предпросмотр и проверка полей принтера учитывают выбранный формат.

Импорт публичного .cer на клиентском компьютере перенесён в окно входа:
«Доверие из .cer…». Локальный мастер запускается на самом Reference-сервере.
Программа поддерживает HTTP и HTTPS; протокол должен соответствовать настройке порта.
Новый сертификат не переводит HTTPS-порт на HTTP.

Распакуйте ZIP в новую папку. .NET отдельно не требуется.
Инструкция — docs/certificate-wizard.md.
