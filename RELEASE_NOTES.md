Версия 0.3.0 для Windows x64.

Добавлен встроенный мастер сертификата: кнопка «Сертификат…» в программе или
Certificate-Wizard.cmd из архива. Находит службы/процессы RefSrv, порты и сертификаты,
показывает срок и SHA256, готовит новый mylocal.pem и резервную копию.

Шаги: поиск → отключение сервера → проверка остановки службы, процесса и порта →
«Далее» → установка и доверие → «Сервер можно включить» → проверка запуска, порта
и нового HTTPS-сертификата → «Далее» → «Завершить».
Службой можно управлять кнопками мастера. Принудительного завершения RefSrv нет.
Есть откат. Если нужен только импорт проверенного действующего сертификата,
мастер может настроить доверие без перевыпуска и перезапуска.

Для клиента на другом компьютере предусмотрен импорт публичного .cer с проверкой
совпадения с сертификатом порта. Для замены файла запустите мастер на Reference-сервере.
Права администратора нужны для службы и доверия всем пользователям компьютера.

Ручной вход, автовход и обновление меню теперь предваряются проверкой TCP/HTTPS
без отправки учётных данных. Вход блокируется при ошибке порта/сертификата.
Проверка TLS не отключается. Сохранённые профили и пять шаблонов 0.2.0 сохранены.

Распакуйте ZIP в новую папку и запустите Kushat.exe. .NET отдельно не требуется.
Порядок настройки — docs/certificate-wizard.md в архиве.
